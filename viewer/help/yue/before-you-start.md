# 開始之前

你需要一個 account、一個支援嘅瀏覽器同 viewer 嘅網址；電腦唔使裝任何嘢。

<strong>呢本手冊都有網上版：</strong> 每版頂部嘅 <strong>?</strong> 會喺 viewer 入面打開，直接去嗰版嘅章節，可以搜尋，又可以轉 English／廣東話。永遠係最新版本。

<strong>你嘅 account</strong>

- Admin 會幫你開 account，再寄邀請俾你，入面有一個<strong>臨時密碼</strong>。
- 打開 viewer 網址，用你嘅 <strong>Email</strong> 同臨時密碼登入，跟住喺彈出嚟嘅 <strong>My account</strong> 版揀返自己嘅密碼（最少 8 個字）。
- 每個瀏覽器會保持登入 30 日。15 分鐘內打錯 10 次密碼，登入會停 15 分鐘。
- 角色係逐個 project 設定：<strong>Project admin</strong>、<strong>Member</strong> 或者 <strong>Viewer</strong>（睇「俾 admin 嘅」）。Viewer 會見到一條橫額，話佢只可以睇同讀，唔改得任何嘢。

<strong>Viewer 網址：</strong>[寄出之前喺度貼上 viewer 網址]

<strong>瀏覽器同裝置</strong>

| 裝置 | 瀏覽器 | 備註 |
|---|---|---|
| Windows 或者 Mac | Chrome 或者 Edge（建議）、Safari、Firefox | 有中鍵（滾輪）嘅滑鼠，用 3D 會容易好多 |
| iPad | Safari | Apple Pencil 可以畫 markup；建議打橫用 |
| iPhone | Safari | 最適合睇同讀；3D 會載一個輕啲嘅 model |

<strong>保密</strong>

- 當 viewer 係 project folder 咁對待：只可以加 project 團隊入面嘅人。
- 唔好分享密碼、唔好轉寄邀請 email，亦唔好喺團隊以外貼連結。
- 截圖同 export 出嚟嘅 PDF，跟其他 project 文件一樣嘅規矩。
