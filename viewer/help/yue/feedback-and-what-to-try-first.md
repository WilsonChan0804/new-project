# 意見同先試乜

呢個係試用版：請試吓下面啲嘢，話俾我哋知乜嘢好用、乜嘢搞唔清、仲欠乜。

- ☐ Sign in 同改密碼
- ☐ 搜尋一個房名或者 note 搵一張 sheet
- ☐ 喺 sheet 上面畫一個 cloud 加文字，再變成 issue
- ☐ 喺 3D 打開同一個位置，切一個 floor plan
- ☐ 開住 <strong>Straight</strong>，喺 plan 量一間房牆到牆
- ☐ 喺 3D 開一個 issue，派俾同事，再用 @mention 寫 comment
- ☐ 試 <strong>2D + 3D</strong>，一路行走廊一路睇 plan
- ☐ 喺 iPad 或者 iPhone 打開 viewer 睇一層
- ☐ 由你嘅測試 issue 開一個 task，然後喺 Tasks 版完成佢同解決個 issue
- ☐ 喺你 project 嘅 channel 發一條有 # task 同 $ sheet 連結嘅訊息
- ☐ 喺你嘅 project channel 開一個 topic，pin 一條訊息，再發一個 poll 同一個 event
- ☐ 用 Ctrl+K 搵你嘅測試 issue
- ☐ 喺 3D 撳一個元件，撳 Copy Revit ID，再喺 Revit 用 Select by ID 揀中佢
- ☐ 試完刪咗你嘅測試 issue 同 task

意見、問題同問題報告請傳去 [名 / Teams channel]。同速度或者 crash 有關嘅，請夾埋 Performance 報告。
