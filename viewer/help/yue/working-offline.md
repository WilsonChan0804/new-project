# 離線工作

喺地盤冇訊號嘅時候，下載咗落部機嘅 project 照樣用得：sheet、3D model、issue 同 markup。

1. 有網絡嗰陣，打開個 project，撳頂部嘅 <strong>Offline</strong>，再撳 <strong>Download for offline</strong>。下載會顯示進度，斷咗可以繼續。
2. 冇網絡嗰陣，頂部會寫 <strong>Offline - copy of &lt;日期&gt;</strong>。可以睇 sheet 同 model、開同回覆 issue、畫 markup。
3. 離線做嘅改動會喺部機度等（<strong>N changes waiting</strong>），網絡返嚟就會自己 upload（<strong>All changes uploaded</strong>）。

- Dashboard、Admin、Board、Tasks、Messenger、同舊版本比較同加 PDF 都要有網絡。
- 喺 iPad 同 iPhone，先 <strong>Add to Home Screen</strong>：Safari 可能會清走幾個禮拜冇開過嘅網站，但 Home Screen 嘅 app 會保留。
