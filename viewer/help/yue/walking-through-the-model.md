# 喺 model 入面行

Walk 模式將你放喺棟樓入面眼睛嘅高度，跟住樓板、樓梯同斜路行。

<strong>開始：</strong> 撳 <strong>Walk</strong>，然後撳一塊樓板（撳牆會將你放喺牆前面嘅樓板）。或者右鍵撳一個位揀 <strong>Walk from here</strong>。開始行會熄 floor plan 同 section box。

| 動作 | 鍵盤／滑鼠 | iPad / iPhone |
|---|---|---|
| 向前／向後 | W / S 或者 ↑ / ↓ | 畫面上嘅控制板 |
| 打側行 | A / D | 畫面上嘅控制板 |
| 轉身 | ← / →，或者用滑鼠拖 | 用手指拖，或者控制板 |
| 望上望落 | 用滑鼠拖 | 用手指拖 |
| 快啲 | 㩒住 Shift（3 倍速） | - |
| 向前或者向後一步 | 碌滑鼠轆 | - |
| 上一層／下一層 | Page Up / Page Down | - |
| 升／降（Gravity 熄咗） | E / Q | - |
| 停 | Esc 或者 <strong>Stop</strong> | <strong>Stop</strong> |

<strong>Walking panel 設定</strong>（會記住）：

- <strong>Eye</strong> 眼睛高度，0.8 至 3 m（預設 1.6 m）。
- <strong>Speed</strong> 速度，0.5 至 8 m/s（預設 1.5 m/s）。
- <strong>Gravity</strong>（開）：企喺樓板上面，行得上樓梯同斜路，唔理檯咁高嘅級。
- <strong>Walls block</strong>（熄）：唔俾你穿牆。Model 入面啲門係閂住嘅，所以開咗呢個連門口都會擋住。

喺 Sheets 版用 <strong>2D + 3D</strong> 加 <strong>Walk</strong>，就可以喺 3D 行，隔籬嘅 plan 會顯示你喺邊。
