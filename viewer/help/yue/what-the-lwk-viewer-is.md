# LWK Viewer 係乜嘢

LWK Viewer 喺網頁瀏覽器入面顯示 project 嘅 Revit sheet 同 3D model，所以團隊入面任何人唔使開 Revit 都可以睇圖、度尺、畫 markup 同開 issue。電腦、iPad 同 iPhone 都用得，每個開咗嘅 issue 會即時同晒成個團隊分享，仲可以喺 Revit 入面跟返。

除咗圖則同 model，佢仲放埋團隊嘅工作：project 清單、task list（取代 Lark Tasks）、白板同 Messenger，全部都連住同一批 sheet、3D 視圖同 issue，仲有一個搜尋可以一次過搵晒所有嘢。

<strong>邊個會用</strong>

| 邊個 | 通常用嚟 |
|---|---|
| 建築師同設計師 | 睇圖同 3D model，開設計同協調 issue，回覆指派俾自己嘅 issue |
| Project lead 同 director | 用平板睇進度，喺 Dashboard 跟進未完成同過咗期嘅 issue |
| BIM coordinator | 由 Revit publish model 同 sheet，行晚間 export，喺 Revit 入面處理 issue |
| 顧問同地盤同事（Viewer 角色） | 任何裝置都只係睇同讀 |
| Team lead | 安排團隊嘅 task list，跟進邊個幾時要做乜，喺 project channel 傾 |
| Project admin 同 site admin | 加人、set 角色、管理 project |

<strong>可以做乜</strong>

- <strong>Sheets (2D)：</strong> 打開每張 publish 咗嘅 sheet，係清晰嘅 PDF；搜尋所有圖則上面嘅字；用 20 幾款工具畫 markup；同舊版本比較；連 markup 一齊 export PDF。
- <strong>3D：</strong> 轉、移、喺 model 同佢嘅 link 入面行；切平面圖同剖面；有 snap 咁度尺；睇元件 property；儲存視圖。
- <strong>Issue：</strong> 喺 sheet 或者 3D 開 issue，會連一張截圖；指派俾人、set 限期、用 @mention 留言，一路跟到關為止。Issue 可以透過 BCF 同 Revit、Navisworks、BIMcollab 互通。
- <strong>2D + 3D 並排：</strong> 喺 sheet 上面撳平面圖，3D 就會去返嗰度；喺 3D 行嘅時候，平面圖會顯示你喺邊。
- <strong>Revit 連接：</strong> Revit 入面嘅 LWK Issues 視窗會列出同一批 issue，可以 zoom 去嗰度，亦可以傳回覆返嚟。
- <strong>Projects：</strong> 每個 job 嘅人、圖則、model、task、issue、檔案同 chat 都喺同一版。
- <strong>Tasks：</strong> 團隊 task list，有 List、Kanban、Gantt 同 Dashboard 幾種睇法，可以由 Lark import，亦連住 issue、sheet 同 3D 視圖。
- <strong>Board：</strong> 每個 project 一塊共用白板，可以寫 note、整 mind map 同畫草圖。
- <strong>Messenger：</strong> project channel、group chat 同私訊；task 同 issue 嘅更新會自動貼入嚟；可以連去 task、issue、sheet 同 3D；仲可以同 WhatsApp 互傳訊息。
- <strong>Issue 同 Task 打通：</strong> 由 issue 直接開 task；完成其中一樣，會問你要唔要一齊關埋另一樣。
- <strong>Revit 元件：</strong> 3D issue 會記住 Revit ElementId，用嚟做 Select by ID、BCF 同 LWK add-in。
- <strong>搜尋：</strong> 一個搜尋框（Ctrl+K）搵晒 task、issue、sheet、3D 視圖、訊息同檔案連結。
- <strong>Offline：</strong> 將 project 下載落平板，喺地盤冇訊號都照用得。
