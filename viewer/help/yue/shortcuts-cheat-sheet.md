# 快捷鍵一覽

印咗呢個表，或者頭一個禮拜放喺 screen 隔籬。

| 喺邊 | 鍵或者掣 | 做乜 |
|---|---|---|
| 3D | 右掣拖 | 轉 |
| 3D | 中間掣拖 | Pan |
| 3D | 滑鼠轆 | 向住游標 zoom |
| 3D | Double-click | 對準嗰個面 |
| 3D | 右鍵撳（唔拖） | 選單，同將轉嘅中心搬去嗰度 |
| 3D | Page Up / Page Down | 上一層／下一層 |
| 3D | Esc | 取消量度、停止行、閂選單 |
| 3D 量度 | Shift | 下一點開／熄 Straight |
| 3D 行 | W A S D、↑ ↓ | 行同打側行 |
| 3D 行 | ← → | 轉身 |
| 3D 行 | Shift / Q / E | 快啲／降／升（Gravity 熄咗） |
| Sheets | 滑鼠轆／中間掣拖 | Zoom / pan |
| Sheets | Page Down / Page Up | 下一張／上一張 sheet |
| Sheets | V / H | Select 工具／Pan 工具 |
| Sheets | Enter、Esc、Backspace | Polyline 完成、結束，或者刪最後一點 |
| Sheets | Delete | 刪揀咗嘅 markup |
| Sheets | Ctrl+A | 揀晒張 sheet 嘅 markup |
| Sheets | Ctrl+C / Ctrl+V | Copy／貼 markup（貼去另一張 sheet 都得） |
| Sheets | Ctrl+Z / Ctrl+Y | Undo / redo |
| Sheets | R / Shift+R | 揀咗嘅順時針／逆時針轉 90° |
| Sheets compare | N / Shift+N | 下一個／上一個改動 |
| 每一版 | Ctrl+K 或者 / | 搜尋所有嘢 |
| 搜尋 | ↑ ↓、Enter、Esc | 移動、打開、閂 |
| Tasks | K / J | 上一個／下一個 task |
| Messenger | Enter / Ctrl+Enter | 換行／發送 |
| Messenger | @ # ! $ % | Mention 人／連結 task、issue、sheet、3D 視圖 |
| Messenger | Ctrl+Enter / Esc（改緊訊息） | 儲存／取消改訊息 |
| Messenger | Ctrl+B / Ctrl+I / Ctrl+Shift+X | 粗體／斜體／刪除線 |
