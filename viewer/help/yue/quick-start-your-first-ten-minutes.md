# 快速上手：頭十分鐘

登入、打開一張 sheet、喺 3D 睇返同一個位，再開一個測試 issue。

1. <strong>登入。</strong> 打開 viewer 網址，輸入 email 同密碼，到時跟指示改咗個臨時密碼佢。
2. <strong>揀 project。</strong> 用頂部嘅 project 名（如果你喺多過一個 project，會有下拉選單），或者喺 <strong>Dashboard</strong> 揀。
3. <strong>打開一張 sheet。</strong> 喺 <strong>Sheets</strong> 撳左邊清單入面嘅 sheet，或者喺 <strong>Search all sheets</strong> 打房名、grid 或者 note。滾輪放大縮細，㩒住中鍵拖動，撳 <strong>Fit</strong> 睇成張圖。
4. <strong>去 3D。</strong> 撳左上角嘅 <strong>3D</strong>。㩒住右鍵轉，㩒住中鍵移，滾輪放大縮細。Double-click 一個面就會 zoom 埋去。
5. <strong>睇一層。</strong> 喺 <strong>Floor plan</strong> 下拉選單揀一層：model 會喺嗰層上面 1.2 m 切開，由上面望落去。<strong>Page Up / Page Down</strong> 上落一層；<strong>Whole building</strong> 返去 3D。
6. <strong>撳一件元件</strong>，右邊嘅 <strong>Selection</strong> panel 會顯示佢嘅 property。
7. <strong>開一個測試 issue。</strong> 撳 <strong>Add issue</strong>，撳一個面，打個標題例如「TEST - please ignore」，然後 <strong>Save issue</strong>。所有人都會喺 <strong>Issues in 3D</strong> 見到。
8. <strong>試吓 2D + 3D。</strong> 返去 Sheets，打開一張平面圖，撳 <strong>2D + 3D</strong>；喺平面圖上面撳，3D 就會移去嗰度。
9. <strong>由佢開一個 task。</strong> 打開個測試 issue，撳 <strong>+ New task from this issue</strong>，睇吓 list、負責人同限期啱唔啱，再撳 <strong>Make the task</strong>。
10. <strong>喺 Chat 打個招呼。</strong> 打開 <strong>Chat</strong>，揀 project 嘅 channel，打 <strong>#</strong> 揀你個測試 task，再撳 <strong>Send</strong>。
11. <strong>搜尋。</strong> 按 <strong>Ctrl+K</strong>（或者撳頂部個放大鏡），打 issue 標題入面一個字：issue、task 同你個訊息都會搵到。
12. <strong>做完記得刪除測試 issue 同 task：</strong> issue 喺佢嘅詳情視窗撳 <strong>Delete</strong>，task 喺佢嘅視窗撳垃圾桶掣。
