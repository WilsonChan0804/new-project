# 搜尋

一個格搵晒所有嘢：喺任何一版按 <strong>Ctrl+K</strong> 或者 <strong>/</strong>，或者撳頂部個放大鏡。

- 佢會搵 <strong>project</strong>、<strong>task</strong>（標題、描述、T-12）、<strong>issue</strong>（#12、標題、描述、sheet、負責人、Revit 元件同 id）、<strong>sheet</strong>、儲存咗嘅 <strong>3D 視圖</strong>、<strong>訊息</strong>，同 task 同 issue 上面嘅<strong>檔案同連結</strong>。
- 打一個或者幾個字；每個字都要對到。結果按種類分組；↑ ↓ 同 <strong>Enter</strong> 打開，<strong>Esc</strong> 閂。
- 你只會見到你有權打開嘅嘢。個格空白嗰陣會列出你最近搜尋過嘅。
