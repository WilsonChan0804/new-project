# Projects 項目

<strong>排序：</strong> project 按狀態排 - <strong>Active</strong> 先，跟住 <strong>On hold</strong>、<strong>Completed</strong>、<strong>Archived</strong> - 同一狀態再按名排。Projects 版同所有 project 選單（Sheets、3D、Board、Dashboard、Folders、Messenger）都用呢個次序。喺 Projects 版撳欄目標題（Project、Status、Tasks、Completion、Overdue、Issues）或者用 <strong>Sort</strong> 可以轉其他排法；再撳一次就倒轉。會記住你嘅選擇。

Sheets、3D、Board 同 Dashboard 頂部嘅 project 選單分開兩個：先揀 <strong>project</strong>（名 · 編號），再揀<strong>佢嘅 model 或者 sheet set</strong>（例如 Site 1／Site 2，或者 Sheets 版嘅「Revit sheets」同每個上載咗嘅 PDF set）。

喺 project 嘅資料欄，<strong>Project information</strong> 可以記低 project no.、client、地址、建築類型、地盤面積、GFA、層數、階段、開始同完成日期同簡介（<strong>Edit</strong>，project owner 同 admin 先改得）。撳或者拖一張相落資料欄頂部，就可以俾個 project 一張<strong>相</strong>，清單入面都會見到。

<strong>Projects</strong> 版列出團隊嘅 job，每個 job 嘅人、圖則、model、task、issue、檔案同 chat 都喺同一個地方。呢版係俾人睇嘅；admin 喺 <strong>Admin &gt; Projects and members</strong> 設定 project（撳 <strong>Manage</strong> 掣會帶你去）。

<strong>清單</strong>

| 欄 | 顯示 |
|---|---|
| Project | 簡稱同編號，例如 SKW · HKA-P-01681-ARC |
| Open | <strong>Sheets</strong>、<strong>3D</strong> 同 <strong>Dashboard</strong> 掣。由幾個 model 組成嘅 project（MOS Site 1、Site 2），每個掣都會彈出一個細選單俾你揀邊部分 |
| Tasks | 進度（做咗幾多／總數）、過咗期嘅 task 同未完成嘅 task，嚟自每個有呢個 project group 嘅團隊 list |
| Issues | 按狀態分色嘅 issue 條，同埋未完成／總數；過咗期嘅會用紅色。會加埋 project 所有 model |
| Folders | OneDrive、SharePoint 或者 ACC 嘅 folder |
| Chat | Messenger 入面 project 嘅 channel，同埋未讀訊息 |

- 頂部可以搜尋 project 或者人名，亦可以按狀態篩選。
- 撳一行睇<strong>詳情</strong>：按團隊分嘅成員、按狀態分嘅 issue（撳個數字會打開 Dashboard）、task 連 sub-task，同埋 <strong>Models and sheets</strong>：每個部分都有自己嘅 Sheets、3D 同 Dashboard 連結。
- <strong>一個 project，幾個 model。</strong> 一個 job 如果 export 做幾個 Revit model 同 sheet set，仍然係一個 project，分開幾個部分。成員係所有部分嘅人加埋，issue 數目會加埋所有部分，project 下拉選單會將佢顯示做一組。
