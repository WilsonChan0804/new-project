# 通知同 app

有新訊息唔使 refresh 都會通知你，viewer 仲可以裝成一個 app。

- <strong>開住任何一版 viewer 嘅時候</strong>（任何一版、背景嘅分頁，或者個 app）：新訊息會喺 Windows、Mac 同 Android 彈通知；撳一下就打開嗰個 chat 去到嗰條訊息。你睇緊嗰個 chat 就唔會彈。分頁標題會顯示未讀數，例如 <strong>(3) LWK Viewer</strong>，app 個 icon 都會有。
- <strong>頂部嘅鈴</strong>：撳 <strong>Turn on notifications</strong>（瀏覽器會問一次），再揀 <strong>Every message</strong>（所有訊息）、<strong>@mentions and direct messages</strong>（只係 @你 同私訊）或者 <strong>Nothing</strong>（唔通知）。
- <strong>某個 chat 靜音：</strong> Chat info &gt; <strong>Mute notifications</strong>。靜咗音嘅 chat 有人 @你 都照通知。
- <strong>唔止訊息：</strong> 有 task 派咗俾你、有人喺 task 或者 issue 度 @你、有 issue 派咗俾你或者你嘅 query 有人答、你嘅 task 就快到期，都會通知你。鈴入面嘅 <strong>For you</strong> 清單列出最近嘅（紅色數字係未睇嘅）；撳一項就打開，<strong>Mark all read</strong> 清咗個數字。
- <strong>裝 app：</strong> 鈴 &gt; <strong>Install the app</strong>（Edge、Chrome），或者網址列右邊嘅安裝 icon。Android：選單 &gt; <strong>Add to Home screen</strong>。iPhone／iPad：Safari &gt; 分享 &gt; <strong>加至主畫面</strong>。App 會用自己嘅視窗打開，右撳 icon 有 Chat、Tasks、Calendar、Folders 同 Projects 捷徑。
- <strong>冇開任何一版都收到（push）：</strong> 鈴 &gt; <strong>Turn on for this device</strong>。要用 viewer 嘅 <strong>https</strong> 地址開先得（問你嘅 admin）。之後就算 app 閂咗，部手機或者電腦都會收到訊息。
- <strong>iPhone／iPad：</strong> 先喺 Safari &gt; 分享 &gt; <strong>加至主畫面</strong>，再由主畫面個 icon 打開；然後喺鈴度開通知、撳 <strong>Turn on for this device</strong>，再撳 <strong>Send a test</strong>。收唔到嘅話，會講埋原因（例如 server 連唔到 Apple）。Server 更新之後，請關一次再開一次 push。
