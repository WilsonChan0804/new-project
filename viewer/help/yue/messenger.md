# Messenger 訊息

<strong>Chat</strong> 會打開 Messenger：團隊嘅對話，就喺佢哋講緊嘅工作隔籬。

<strong>Chat 嘅種類</strong>

| Chat | 係乜 |
|---|---|
| Project channel | 每個 project 一個，project 所有人都喺入面。新 task、指派、完成、task 留言同新開或者改咗嘅 issue 會用卡片貼入嚟 |
| Topic | Project channel 入面講一樣嘢嘅分台（例如 Facade、MEP coordination、Site visits）。會列喺 channel 下面，亦會喺 channel 名下面做 tab 顯示：<strong># General</strong> 就係 channel 本身 |
| Group | 任何一班人，由開 group 嘅人改名 |
| Direct message | 兩個人 |
| Task discussion | 你 follow 緊嘅 task 嘅留言，可以喺度直接回覆 |

- 頂部支筆開新 chat。喺 chat 上面撳右鍵（手機就㩒住佢）會有 <strong>Details</strong>、<strong>Mark as read</strong>、<strong>New topic</strong>（project channel）、<strong>Leave</strong>、<strong>Import WhatsApp chat ...</strong>、<strong>Send chat link to WhatsApp</strong>，有權刪嘅人仲有 <strong>Delete chat</strong>。
- <strong>開 topic：</strong> project channel 入面任何人都可以喺 channel 名下面嘅 tab 撳 <strong>+ Topic</strong>（或者 channel 選單嘅 <strong>New topic</strong>，或者支筆 &gt; <strong>Topic in a project channel</strong>）。Channel 入面所有人都會加入去。
- <strong>邊個可以刪 chat：</strong> direct message 係兩個人任何一個（刪咗兩邊都冇）；group 係佢嘅 admin（開 group 嘅人）或者 site admin；project channel 同 topic 係 project 嘅 admin 或者 site admin。刪 channel 會連佢嘅 topic 一齊刪。
- <strong>Chat info</strong>（人仔掣）：描述、成員（加、移除、私訊）、<strong>Pictures and files</strong>、<strong>Leave this chat</strong> 同 <strong>Delete this chat</strong>。
- 每一版頂部 <strong>Chat</strong> 上面嘅數字係未讀訊息；<strong>@</strong> 即係有人 mention 你。

<strong>打字</strong>

- <strong>Enter</strong> 係換行；撳 <strong>Send</strong> 掣先會發送（用鍵盤嘅話，<strong>Ctrl+Enter</strong> 都會發送）。
- 可以貼或者拖截圖入嚟，或者用夾萬（📎）傳相同檔案，每個最大 50 MB。OneDrive、SharePoint 同 ACC 連結會顯示做卡片；影片連結會有播放卡，貼 OneDrive 或 SharePoint 嘅 <strong>Embed</strong> code 就可以喺 chat 入面直接播。
- <strong>@</strong> 一個人。<strong>#</strong> 一個 task、<strong>!</strong> 一個 issue、<strong>$</strong> 一張 sheet、<strong>%</strong> 3D model 或者儲存咗嘅視圖：一打就會彈出清單。<strong>先揀 project</strong>：清單最頂有一排 project 俾你揀（喺 project channel 會預先揀好嗰個 project）。夾萬隔籬嘅 <strong>#</strong> 掣會打開同一啲清單，有分頁。
- 揀咗嘅項目會喺訊息入面變成一條有名嘅連結，撳就打開。
- 🙂 可以加 emoji。
- <strong>格式（Aa）：</strong> 好似 Lark 咁，輸入框直接顯示發出去嘅樣。<strong>Aa</strong> 會顯示格式掣：<strong>B</strong>、<strong>S</strong>、<strong>I</strong>、<strong>U</strong>、編號同 bullet 清單、引用、連結、code 同 code block；<strong>Ctrl+B</strong>、<strong>Ctrl+I</strong>、<strong>Ctrl+U</strong> 同 <strong>Ctrl+Shift+X</strong> 對揀咗嘅字用。手機上面撳 <strong>Aa</strong> 之後格式掣會自己一行出現。轉去 WhatsApp 都會保留粗體、斜體同刪除線。
- <strong>輸入框下面嘅掣：</strong> <strong>Aa</strong>、🙂 emoji、<strong>@</strong> 人、<strong>#</strong> task、issue、sheet 或者 3D 視圖（喺框入面顯示做 chip）、夾萬、<strong>+</strong> 同 <strong>Send</strong>；<strong>Send</strong> 永遠喺畫面入面，手機都係。
- <strong>+ 掣：</strong> <strong>Poll</strong>、<strong>Event / meeting</strong>、<strong>Task</strong>，或者連結一個 task、issue、sheet 或者 3D 視圖。

<strong>投票、活動同 task</strong>

- <strong>Poll（投票）：</strong> 一條問題，2 至 10 個選擇；想嘅話剔 <strong>Allow more than one answer</strong>、<strong>Anonymous</strong> 或者揀截止日期。撳一個選擇就投票，再撳就取消。寫嘅人可以 <strong>Close poll</strong>（亦可以重開）。
- <strong>Event（活動）：</strong> 標題、日期、時間（或者 <strong>All day</strong>）、地點同 Teams 連結。Chat 入面所有人都會收到邀請（mail 設定好嘅話仲會有 email），可以答 <strong>Going</strong>、<strong>Maybe</strong> 或者 <strong>Can't go</strong>。<strong>Add to calendar (.ics)</strong> 可以放入 Outlook、Google 或者手機日曆。寫嘅人可以 <strong>Change</strong> 或者 <strong>Cancel event</strong>；chat 會收到通知。
- <strong>Task：</strong> 揀 task list 同 group（呢個 project 嘅排先）、負責人（呢個 chat 嘅人排先）、到期日同優先次序。Task 會放入個 list，佢張卡片會出現喺 chat。喺任何訊息撳 ⋯ More &gt; <strong>Make a task</strong> 都一樣，訊息會變成描述，@mention 咗嘅人做負責人，仲有條連結返去嗰條訊息。

<strong>一條訊息</strong>

- 滑鼠移到訊息上面（手機就撳一下）：🙂 <strong>React</strong>、↩ <strong>Reply</strong>、✏ <strong>Edit</strong>（自己嘅訊息）同 ⋯ <strong>More</strong>：<strong>Copy</strong>、<strong>Pin</strong>、<strong>Make a task</strong>、<strong>Forward to another chat</strong>、<strong>Send to WhatsApp</strong>、<strong>Copy link to this message</strong> 同 <strong>Delete</strong>（自己嘅訊息）。
- <strong>Edit</strong> 直接喺原位改：<strong>Ctrl+Enter</strong> 儲存，<strong>Esc</strong> 取消；其他人會見到「(edited)」。<strong>Edit</strong> 同 <strong>Delete</strong> 只限發訊息嘅人（chat 嘅 admin 同 site admin 都唔得）；其他人會見到「message deleted」。
- <strong>Pin 訊息：</strong> chat 入面任何人都可以 pin 訊息，每個 chat 最多 100 條。Chat 名下面嗰條會顯示最新 pin 嘅一條；撳佢就去睇嗰條訊息，再轉去下一條；<strong>All</strong> 會列晒出嚟，可以 <strong>unpin</strong>。
- <strong>Reaction</strong> 會喺訊息下面顯示，連數目；撳一下就加或者攞走你嘅。
- 發唔到嘅訊息會留低，有 <strong>send again</strong> 俾你再試。

<strong>WhatsApp</strong>

- <strong>轉出去：</strong> 訊息上面嘅 <strong>Send to WhatsApp</strong> 會將文字、連結同檔案傳出去。手機上面相片會原本咁經分享選單傳過去；電腦就會打開 WhatsApp Desktop 或者 WhatsApp Web。
- <strong>Copy 咗嘅訊息：</strong> 喺 WhatsApp copy 幾條訊息，貼入輸入框，會問你係咪變成一個「From WhatsApp」引用。
- <strong>匯出成個 chat：</strong> 喺 WhatsApp 打開個 chat &gt; <strong>More</strong> &gt; <strong>Export chat</strong>，將 .zip（有相）或者 .txt 傳俾自己。然後喺 chat 選單揀 <strong>Import WhatsApp chat ...</strong>：啲訊息會變成一個引用，相片放返喺原本嘅位置。
- <strong>Android：</strong> 將 viewer 安裝做 app 之後，喺 WhatsApp 撳 <strong>Share</strong> &gt; <strong>LWK Viewer</strong>，再揀 chat。（iPhone 唔支援：用 copy 貼上，或者匯出。）
- 同 WhatsApp 之間冇自動雙向同步。
