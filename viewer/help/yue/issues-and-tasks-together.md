# Issue 同 task 連埋一齊

Issue 講咩出咗問題；task 講邊個幾時之前改好。兩樣連埋一齊，每一邊都會問你要唔要順手閂埋另一邊。

- <strong>由 issue 開 task：</strong> 喺 issue 視窗撳 <strong>+ New task from this issue</strong>。呢個 project 嘅 task list 同 group 會排先，負責人係 issue 嘅 <strong>Assigned to</strong>，到期日同 issue 一樣。Issue、佢嘅檔案同 Revit 元件都會放落個 task。剔 <strong>Open the task when made</strong> 就會開完即刻去個 task。
- <strong>Task 完成 → issue：</strong> 當你 <strong>Mark complete</strong> 一個 task，而佢連住嘅 issue 仲未閂，Tasks 會問 <strong>Resolve its issues too?</strong> 剔要改嘅，揀 Resolved 或者 Closed。改法同你喺 viewer 自己改一樣：有歷史、email、chat 卡片，同一條寫明係邊個 task 嘅 comment。
- <strong>Issue 解決 → task：</strong> 將 issue 改做 Resolved 或者 Closed 再 <strong>Save</strong>；如果佢嘅 task 仲未完成，viewer 會問你要唔要剔佢哋做完成。啲 task 嘅 activity 都會多一行記錄。
- Task 視窗會顯示每個相連 issue 而家嘅狀態；task 清單會顯示 <strong>#n open</strong> 或者 <strong>#✓</strong>。
