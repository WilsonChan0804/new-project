# 手機同平板

同一個網址喺 iPad 同 iPhone 嘅 Safari 都用得；viewer 會認出部機，載入輕啲嘅 3D model，等部機記憶體夠用。

<strong>手機或者平板有乜唔同</strong>

- 側邊 panel 變成抽屜：左邊 <strong>☰ Models</strong> / <strong>☰ Sheets</strong>，右邊 <strong>ⓘ Details</strong> / <strong>Issues</strong>。撳抽屜外面就閂。Details 上面有粒點即係揀咗嘢。
- 3D 會載入每個 model 嘅手機版，每次 publish 之後 server 會整。大 project 嘅幾何會跟住你望邊度一嚿嚿攞（「streaming」），先粗後幼。
- <strong>Light mode</strong> 開咗：重複嘅標準層只會喺你望緊嘅附近載入。
- 傢俬呢啲細嘢只會喺鏡頭附近畫，遠嘅部分用簡化咗嘅形狀。
- 切到嘅實體有橙色 hatch，但冇啡色輪廓線。
- 頂部可以打橫碌：掃一掃就見到 Board、Tasks、Chat 同 Dashboard。
- <strong>Search</strong> 會佔滿成個畫面。喺 <strong>Messenger</strong>，撳一下訊息就出佢嘅掣；Enter 係換行，撳圓形掣先發送。

<strong>手勢</strong>

| 手勢 | 3D | Sheets |
|---|---|---|
| 一隻手指 | 轉 | 用而家嘅工具畫（用過 Apple Pencil 之後就係 pan） |
| 兩隻手指 | 捏 zoom，拖 pan | 捏 zoom，拖 pan |
| Double tap | 對準嗰個面 | - |
| 㩒住 | 喺嗰點開新 issue | 右鍵選單 |
| 兩隻／三隻手指 tap | - | Undo / redo |

<strong>貼士</strong>

- iPad 打橫用，畫圖嘅位最多。
- 如果個 model 啱啱幾分鐘前先 publish，手機版可能仲整緊；版面會問你要唔要整，等幾分鐘再試。
- 如果 Safari 自己 reload 個版，即係部機記憶體唔夠：喺 <strong>Models</strong> 唔剔你唔使用嘅 model，留喺一層，再報告（睇「解決問題同常見問題」）。
