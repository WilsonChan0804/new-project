# 3D: moving around

The 3D page uses the same mouse as most BIM viewers: right button orbits, middle button pans, wheel zooms, left button picks.

### Mouse, touch and keys

| Action | Mouse | iPad / iPhone |
|---|---|---|
| Orbit | Hold the right button and drag | One finger |
| Pan | Hold the middle button (wheel) and drag | Two fingers |
| Zoom | Scroll wheel (towards the pointer) | Pinch |
| Focus on a surface | Double-click it | Double tap |
| Select an element | Left click | Tap |
| Set the orbit centre | Right-click without dragging, or right-click menu <strong>Set orbit centre here</strong> | - |
| Menu of actions | Right-click | - |
| New issue at a spot | <strong>Add issue</strong>, then click | Long press (0.6 s) |
| Floor above / below | Page Up / Page Down | Floor plan list |
| Cancel measure or walk | Esc | Stop button |

With a mouse the view stops exactly where you let go; with a finger it glides a little, as on any tablet app.

### Right-click menu

On an element: <strong>Set orbit centre here</strong>, <strong>Zoom to this element</strong>, <strong>Isolate</strong>, <strong>Hide</strong>, <strong>Show all</strong>, <strong>Walk from here</strong>, <strong>Add issue here</strong>, <strong>Section on this face</strong>, <strong>Square section box to this face</strong>, <strong>Turn section on/off</strong>, <strong>Measure</strong>, <strong>Save view...</strong>, <strong>Fit model</strong>. On empty space: Show all, Turn section on/off, Measure, Save view..., Fit model.

### View cube and camera

- Click a <strong>face</strong> of the cube for that view, an <strong>edge</strong> for the view between two faces, a <strong>corner</strong> for an isometric view. Drag the cube to orbit. The ring under it shows north.
- The house button returns to the 3D overview. <strong>Fit</strong> frames all loaded models.
- <strong>Perspective / Parallel</strong> switches the projection (plans are always parallel).
- <strong>Set front:</strong> click a wall to tell the cube which way is "Front" for this building; <strong>World</strong> goes back to the world axes.

### Floors

- The <strong>Floor plan</strong> drop-down lists <strong>Whole building</strong> and every level from the top down.
- Picking a level cuts the model from 0.5 m below to 1.2 m above that floor and looks straight down, like a Revit plan.
- <strong>Page Up / Page Down</strong> step up and down; <strong>Whole building</strong> returns to the full 3D model.
- <strong>Drawing</strong> lays that floor's plan sheet over the model, so you can compare drawing and model.

### Models panel

- One tick box per model (the host model and each link). Untick to hide a model and free memory; <strong>All on / All off</strong> switch them together and keep your view.
- <strong>▸</strong> beside a model shows its size and number of copies, and <strong>Compare with previous export</strong> to see what was added, changed or removed since the last publish.
- <strong>Apply link transforms</strong> (on) places links where they sit in Revit.
- <strong>Light mode (phones, tablets)</strong> loads repeated typical floors only near where you are looking. It is on by default on phones and tablets.
- Every panel heading (Models, Section, Measure, and so on) folds away when clicked, and stays folded next time.
