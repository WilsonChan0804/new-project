# Shortcuts cheat sheet

Print this table or keep it beside the screen for the first week.

| Where | Key or button | Action |
|---|---|---|
| 3D | Right button drag | Orbit |
| 3D | Middle button drag | Pan |
| 3D | Wheel | Zoom towards the pointer |
| 3D | Double-click | Focus on that surface |
| 3D | Right-click (no drag) | Menu, and move the orbit centre there |
| 3D | Page Up / Page Down | Floor above / below |
| 3D | Esc | Cancel a measurement, stop walking, close a menu |
| 3D measure | Shift | Straight on or off for one point |
| 3D walk | W A S D, ↑ ↓ | Move and step sideways |
| 3D walk | ← → | Turn |
| 3D walk | Shift / Q / E | Faster / down / up (Gravity off) |
| Sheets | Wheel / middle drag | Zoom / pan |
| Sheets | Page Down / Page Up | Next / previous sheet |
| Sheets | V / H | Select tool / Pan tool |
| Sheets | Enter, Esc, Backspace | Finish, end, or remove the last point of a polyline |
| Sheets | Delete | Delete the selected markup |
| Sheets | Ctrl+A | Select all markups on the sheet |
| Sheets | Ctrl+C / Ctrl+V | Copy / paste markups (also to another sheet) |
| Sheets | Ctrl+Z / Ctrl+Y | Undo / redo |
| Sheets | R / Shift+R | Rotate the selection 90° clockwise / anticlockwise |
| Sheets compare | N / Shift+N | Next / previous change |
| Every page | Ctrl+K or / | Search everything |
| Search | ↑ ↓, Enter, Esc | Move, open, close |
| Tasks | K / J | Previous / next task |
| Messenger | Enter / Ctrl+Enter | New line / send |
| Messenger | @ # ! $ % | Mention a person / link a task, issue, sheet, 3D view |
| Messenger | Ctrl+Enter / Esc (editing) | Save / cancel an edited message |
| Messenger | Ctrl+B / Ctrl+I / Ctrl+Shift+X | Bold / italic / strikethrough |
