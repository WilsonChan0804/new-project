# Undo

- <strong>Ctrl+Z</strong> (Cmd+Z on a Mac) undoes the last change; <strong>Ctrl+Y</strong> (or Ctrl+Shift+Z) redoes it. A note at the bottom says what was undone, with <strong>Redo</strong>.
- <strong>Tasks:</strong> changed fields, Kanban moves, list drags, Gantt moves, a new task and a deleted task (with its sub-tasks).
- <strong>Messenger:</strong> a deleted message (your own, within a day), an edit, a pin and a reaction.
- <strong>Folders:</strong> delete, rename, move, upload and a new folder.
- While you type in a box, Ctrl+Z undoes the typing as usual. The Sheets and 3D pages keep their own undo for markups.
