## At a glance 重點摘要 {#at-a-glance}

=== "English"

    - Sets the **fees** for registering **minor works contractors** under B(MW)R: applications, registration, renewal, restoration, additional items, classes or types, additional authorised signatories, and reviews.
    - **Part 2: individuals for Class III items** (RMWC (Individual)): see table; review fees are refunded if the BA substitutes its decision (s.8).
    - **Part 3: companies by types and classes** (RMWC (Company)): fees scale with the **highest class**; each extra proposed authorised signatory costs more (s.10). Registration fee **$595** for all classes (s.11).

=== "中文"

    - 訂明根據 B(MW)R 註冊**小型工程承建商**的**費用**：申請、註冊、續期、恢復、增加項目、級別或類型、新增獲授權簽署人及覆核。
    - **第 2 部：個人第 III 級項目**（註冊小型工程承建商（個人））見下表；如建築事務監督以另一決定取代原決定，覆核費退還（第 8 條）。
    - **第 3 部：公司按類型及級別**（註冊小型工程承建商（公司））：費用按**最高級別**計算；每名額外建議獲授權簽署人另加費用（第 10 條）；註冊費各級別均為 **$595**（第 11 條）。

## Key table: main fees 主要費用 {#key-table-main-fees}

| Application 申請 | Class III items (individual) 第 III 級項目（個人） | Class I 第 I 級 | Class II 第 II 級 | Class III only 只限第 III 級 |
|---|---|---|---|---|
| Registration application 註冊申請 | **$290** (relying on own experience) / **$155** | **$2,920** | **$1,100** | **$730** |
| Each extra authorised signatory 每名額外簽署人 | — | $2,440 | $810 | $560 |
| Registration 註冊 | — | $595 | $595 | $595 |
| Renewal 續期 | **$105** | $1,130 | $835 | $425 |
| Restoration 恢復 | **$105** | $1,300 | $915 | $435 |
| Additional classes / types or signatory 增加類型或簽署人 | $290 / $155 (items) | $2,700 | $965 | $615 |
| Review request 覆核 | **$110** | $1,240 | $835 | $410 |

<small>Fees as shown on eLegislation (version date 21/10/2023); check for later amendments before paying. 費用以 eLegislation 版本為準，繳費前請核實。</small>


!!! tip "Does it apply? 是否適用"
    **Applies 適用**: fees payable under the **B(MW)R** for **registered minor works contractors**: individuals (Class III items, Part 2), companies (types and classes, Part 3) and the old **provisional register** (Part 4). **Not** plan fees for building works ([APP-55](../pnap/app-55.md), B(A)R 42) and no fee for **signboard validation** ([APP-155](../pnap/app-155.md)). 小型工程承建商註冊費用。

## Section by section 逐條條文 {#clause-by-clause}

| Section 條 | What it provides 內容 | 中文要點 |
|---|---|---|
| **2(1)** | Definitions: authorized signatory, item, type, **proposed class I / II / III authorized signatory**, register, provisional register | 定義 |
| **2(2)–(3)** | Class I, II, III = Divisions 1, 2, 3 of Schedule 1 Part 3 to the B(MW)R; **Class I is highest**, then II, then III | 級別高低 |
| **3** | Part 2 applies to individual registration for **Class III items** (B(MW)R s.10(1)(a)), renewal, restoration, extra items and review | 第 2 部範圍 |
| **4** | Registration application: **$290** if relying solely on own experience for at least one item, else **$155** | 個人註冊申請 |
| **5–6** | Renewal **$105**; restoration **$105** | 續期、恢復 |
| **7** | Additional Class III items: **$290** / **$155** (same experience test) | 增加項目 |
| **8** | Review request **$110**; **refunded** if the BA substitutes a different decision (B(MW)R s.26(8)(a)(ii)) | 覆核，可退款 |
| **9** | Part 3 applies to company registration by **types and classes** (s.10(1)(b)) and related applications | 第 3 部範圍 |
| **10** | Registration application by **highest class**: I **$2,920**, II **$1,100**, III only **$730**; each **extra** proposed signatory (beyond the first for the highest class): I **$2,440**, II **$810**, III **$560** | 公司註冊申請 |
| **11** | Registration fee **$595** (all classes) | 註冊費 |
| **12** | Renewal: I **$1,130**, II **$835**, III **$425** | 續期 |
| **13** | Restoration: I **$1,300**, II **$915**, III **$435** | 恢復 |
| **14** | Additional classes / types: sum per proposed signatory: I **$2,700**, II **$965**, III **$615** | 增加級別或類型 |
| **15** | Approval of an additional authorized signatory: I **$2,700**, II **$965**, III **$615** | 新增簽署人 |
| **16** | Both applications (s.21(2) and s.24(1)) **together**: sum per individual; an individual in both counts once at the **higher** amount | 同時申請 |
| **17** | Review: sum per signatory involved: I **$1,240**, II **$835**, III **$410**; refunded if decision substituted | 公司覆核 |
| **18–19** | Part 4 **provisional** registration application: I **$865**, II / III **$590**; extra signatory I **$710**, II / III **$480** | 臨時註冊申請 |
| **20** | Provisional registration fee **$315** | 臨時註冊費 |
| **21** | Review (provisional): I **$1,100**, II **$810**, III **$395**; refundable as above | 臨時註冊覆核 |

!!! example "Illustrative only 只作說明"
    A company applies for **Class I and II** types with **3** proposed signatories (2 for Class I, 1 for Class II): application **$2,920** (highest class I, first signatory) + **$2,440** (second Class I) + **$810** (Class II) = **$6,170**; on approval, registration fee **$595**. Renewal later: **$1,130**. 公司註冊例子。
