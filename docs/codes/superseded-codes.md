# Older codes still listed by BD<br><small>屋宇署仍列出的舊守則</small>

BD still lists these codes. The three fire codes have been **replaced** for new designs, but they are still needed when checking **existing buildings** approved under them. The OTTV Code is **still in force**. 以下守則仍載於屋宇署網頁：三份消防守則已被取代，但在核對按其批准的**現有建築物**時仍需參考；總熱傳送值守則**仍然有效**。

| Code 守則 | Status 狀態 | Use today 現時用途 | Source |
|---|---|---|---|
| **Means of Escape in Case of Fire 1996** 《1996 年提供火警逃生途徑守則》 | Replaced by [FS Code 2011 Part B](fsc-part-b-means-of-escape.md) 已被取代 | Checking A&A works to buildings approved before the FS Code; comparing old and new exit widths, travel distances and refuge floors | [PDF](https://www.bd.gov.hk/doc/en/resources/codes-and-references/code-and-design-manuals/MOE1996_e.pdf) |
| **Fire Resisting Construction 1996** 《1996 年耐火結構守則》 | Replaced by [FS Code 2011 Part C](fsc-part-c-fire-resisting-construction.md) | Fire resisting periods and compartments of older buildings | [PDF](https://www.bd.gov.hk/doc/en/resources/codes-and-references/code-and-design-manuals/FRC1996_e.pdf) |
| **Means of Access for Firefighting and Rescue 2004** 《2004 年提供消防和救援進出途徑守則》 | Replaced by [FS Code 2011 Part D](fsc-part-d-means-of-access.md) | Firemen's lifts, firefighting and rescue stairways and EVAs of older buildings | [PDF](https://www.bd.gov.hk/doc/en/resources/codes-and-references/code-and-design-manuals/MOA2004e.pdf) |
| **Overall Thermal Transfer Value in Buildings 1995** 《1995 年建築物的總熱傳送值守則》 | **In force** under the [B(EE)R Cap. 123M](../regulations/beer-123m.md) 仍然有效 | OTTV calculation method for **commercial buildings and hotels**. Current limits are in [APP-67](../pnap/app-67.md): tower **≤ 20 W/m²**, podium **≤ 40 W/m²** (for plans from 31 Dec 2025). Party walls count whether or not a neighbour exists (APSEC 2025) | [PDF](https://www.bd.gov.hk/doc/en/resources/codes-and-references/code-and-design-manuals/OTTV1995_e.pdf) |

!!! tip "When do you still need them? 何時仍需參考"
    - Works **consented on or before 1 Apr 2012** may still use the three fire codes ([APP-153](../pnap/app-153.md) para. 2(a)); A&A to such buildings uses the **FS Code** only for the affected parts. 2012 年 4 月 1 日或之前獲同意的工程。
    - **Cap. 502 / Cap. 572 upgrading** uses the **1995–96** codes (MOE 1996, FRC 1996, MOA 1995), not the 2011 code ([APP-94](../pnap/app-94.md), [APP-145](../pnap/app-145.md)). 消防改善指示。
    - The **OTTV Code** is the current calculation method for hotels and commercial buildings under the B(EE)R. 總熱傳送值守則仍然有效。

## OTTV Code 1995: how OTTV is calculated 總熱傳送值計算 {#ottv-1995}

| Para. | Rule 規定 |
|---|---|
| 1 | OTTV measures the **energy use of the building envelope**; designers may vary glazing, window size, shading, colour and wall type; also daylight and efficient services. Applies to **hotels and commercial buildings** (B(EE)R); ignores internal blinds and shading by neighbours. 概念及範圍。 |
| 2 | Definitions: **building tower** (above the podium), fenestration, lightwell, opaque, **podium** (within **15 m** above ground, or the height allowed by B(P)R 20(3) modification), refuge floor. 定義。 |
| 3 | Code limits: tower **35 W/m²**, podium **80 W/m²**, as an **average** over all walls (or roofs). **Current, stricter limits: [APP-67](../pnap/app-67.md)** (tower **20**, podium **40 W/m²** for plans from 31 Dec 2025). 上限（現行以 APP-67 為準）。 |
| 4.1 | Exclude: external walls of **refuge floors**; walls and roofs of **car park floors**; walls of **lightwells ≤ 21 m²** on plan; walls on roofs. 不計算部分。 |
| 4.2 | **Party walls** are included whether or not a neighbour exists; no shading from neighbours. 共用牆須計算。 |
| 5 | **OTTVw = (Aw × U × α × TDEQw + Afw × SC × ESM × SF) / Aow** (opaque area, U-value, absorptivity, equivalent temperature difference by orientation and wall density, fenestration area, shading coefficient, external shading multiplier, solar factor, gross wall area). 外牆公式。 |
| 6 | **OTTVr = (Ar × U × α × TDEQr + Afr × SC × SF) / Aor**. 屋頂公式。 |
| 7 | **U = 1 / (Ri + Σ x/k + Ra + Ro)** with Tables 1 (conductivity, e.g. normal concrete **2.16**, brick 0.95, glass 1.05 W/m°C), 2 (surface resistances, e.g. external wall Ro **0.044**), 3 (air spaces), 4 (**absorptivity**, e.g. uncoloured concrete 0.65, white mosaic 0.58), 5 (TDEQw by orientation and density), 6–9 (shading, solar factors, roof TDEQ). 傳熱系數及各表。 |
| 8–9 | Windows and doors; submission on standard forms (Schedule); sample calculation (Appendix). 呈交。 |

!!! example "Illustrative only 只作說明"
    A 200 mm normal-weight concrete wall with 20 mm cement render each side: Σx/k = 0.2 / 2.16 + 2 × 0.02 / 0.72 = 0.093 + 0.056 = 0.149; with Ri 0.120 and Ro 0.044, **U = 1 / 0.313 ≈ 3.2 W/m²°C**. This U, the wall colour (α) and orientation (TDEQw) feed the OTTVw formula with the glazing terms. 外牆 U 值例子。
