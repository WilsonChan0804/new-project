# Older codes still listed by BD<br><small>屋宇署仍列出的舊守則</small>

BD still lists these codes. The three fire codes have been **replaced** for new designs, but they are still needed when checking **existing buildings** approved under them. The OTTV Code is **still in force**. 以下守則仍載於屋宇署網頁：三份消防守則已被取代，但在核對按其批准的**現有建築物**時仍需參考；總熱傳送值守則**仍然有效**。

| Code 守則 | Status 狀態 | Use today 現時用途 | Source |
|---|---|---|---|
| **Means of Escape in Case of Fire 1996** 《1996 年提供火警逃生途徑守則》 | Replaced by [FS Code 2011 Part B](fsc-part-b-means-of-escape.md) 已被取代 | Checking A&A works to buildings approved before the FS Code; comparing old and new exit widths, travel distances and refuge floors | [PDF](https://www.bd.gov.hk/doc/en/resources/codes-and-references/code-and-design-manuals/MOE1996_e.pdf) |
| **Fire Resisting Construction 1996** 《1996 年耐火結構守則》 | Replaced by [FS Code 2011 Part C](fsc-part-c-fire-resisting-construction.md) | Fire resisting periods and compartments of older buildings | [PDF](https://www.bd.gov.hk/doc/en/resources/codes-and-references/code-and-design-manuals/FRC1996_e.pdf) |
| **Means of Access for Firefighting and Rescue 2004** 《2004 年提供消防和救援進出途徑守則》 | Replaced by [FS Code 2011 Part D](fsc-part-d-means-of-access.md) | Firemen's lifts, firefighting and rescue stairways and EVAs of older buildings | [PDF](https://www.bd.gov.hk/doc/en/resources/codes-and-references/code-and-design-manuals/MOA2004e.pdf) |
| **Overall Thermal Transfer Value in Buildings 1995** 《1995 年建築物的總熱傳送值守則》 | **In force** under the [B(EE)R Cap. 123M](../regulations/beer-123m.md) 仍然有效 | OTTV calculation method for **commercial buildings and hotels**. Current limits are in [APP-67](../pnap/app-67.md): tower **≤ 20 W/m²**, podium **≤ 40 W/m²** (for plans from 31 Dec 2025). Party walls count whether or not a neighbour exists (APSEC 2025) | [PDF](https://www.bd.gov.hk/doc/en/resources/codes-and-references/code-and-design-manuals/OTTV1995_e.pdf) |

!!! note "Scanned documents 掃描文件"
    Most of these PDFs are scans without searchable text, and the codes are superseded or short, so this page records their status rather than their clauses. 大部分文件為掃描版，本頁只說明其地位。
