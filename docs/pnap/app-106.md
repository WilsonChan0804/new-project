## At a glance 重點摘要 {#at-a-glance}

=== "English"

    - A restaurant kitchen may be treated as **ancillary accommodation** to the restaurant for FRC purposes, provided (para. 1):
    - (a) kitchen enclosed by walls of **FRR ≥ 1 hour**, openings protected by **½-hour doors**;
    - (b) a **protected lobby** between each kitchen door and any **escape route of the main building**, and the **dining area** where the kitchen exceeds **45 m²** usable floor area and the door opens onto an exit route of the dining area.
    - **Hold-open devices** on kitchen doors allowed subject to the FRC Code (para. 2).

=== "中文"

    - 食肆廚房在耐火結構方面可視為食肆的**附屬地方**，條件如下（第 1 段）：
    - (a) 廚房以**耐火 ≥ 1 小時**的牆圍封，開口以**半小時防火門**保護；
    - (b) 每道廚房門與**主建築物的逃生路線**之間設**防護門廊**；如廚房可用樓面面積超過 **45 平方米**而門通往用餐區的出口路線，與**用餐區**之間亦須設防護門廊。
    - 按耐火結構守則，廚房門可裝**常開裝置**（第 2 段）。

!!! warning "Superseded for new works 新工程已不適用"
    Listed in [APP-153 Appendix A](app-153.md#appendix-a): it does **not apply** to buildings designed to the **FS Code 2011**. Current rule: [FS Code C13.2](../codes/fsc-part-c-fire-resisting-construction.md#clause-by-clause) (now **-/60/60** for walls **and** doors). Still relevant to older buildings and Cap. 502 / 572 upgrading. 按 2011 年消防守則設計的建築物不適用。

## Key clauses 條文一覽 {#key-clauses-table}

| Para. 段 | Rule 規定 |
|---|---|
| 1(a) | A **restaurant kitchen** may be treated as **ancillary** to the restaurant for FRC; enclosure walls **FRP ≥ 1 h**, door openings **≥ ½ h**. 廚房牆 1 小時、門半小時。 |
| 1(b) | **Protected lobby** between each kitchen door and: any **escape route** from the main building; and / or the **dining area** if the kitchen is **> 45 m²** and the door opens onto a dining-area exit route. 防護門廊。 |
| 2 | **Hold-open devices** on kitchen doors allowed if FRC Code para. 17.1 is met. 可裝磁扣。 |
| 3 | To be incorporated in the next FRC Code; read para. 6 with this clarification. 納入下一版守則。 |
