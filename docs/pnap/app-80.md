## At a glance 重點摘要 {#at-a-glance}

=== "English"

    - The **FRC Code 1996** (guidance on B(C)R Part XV) revised the 1990 code: clarified anomalies, upgraded some components and removed overlaps with the MOE Code (paras. 1–2).
    - Effective **1 Aug 1996**, not applying to works already under way or consented by then (para. 3).

=== "中文"

    - **1996 年耐火結構守則**（B(C)R 第 XV 部的指引）修訂 1990 年守則：釐清含糊之處、提高部分構件標準，並刪除與走火守則重複的內容（第 1–2 段）。
    - **1996 年 8 月 1 日**生效，不適用於當日或之前已展開或已獲同意的工程（第 3 段）。

!!! warning "Superseded for new works 新工程已不適用"
    Listed in [APP-153 Appendix A](app-153.md#appendix-a); the FRC Code 1996 is replaced by **FS Code 2011 Part C**. Still relevant to buildings consented **1 Aug 1996 – 1 Apr 2012** and to Cap. 502 / 572 upgrading. 由消防守則 C 部取代。

## Key clauses 條文一覽 {#key-clauses-table}

| Para. 段 | Rule 規定 |
|---|---|
| 1 | FRC rules are in **B(C)R Part XV**; the 1990 FRC Code is revised as the **FRC Code 1996**. 1996 年耐火結構守則。 |
| 2 | Clarifies anomalies, **upgrades** some component standards, and removes duplication with the MOE Code. 修訂內容。 |
| 3 | Effective **1 Aug 1996**; not for works being carried out or consented **on or before** that date. 1996 年 8 月 1 日生效。 |
| 4 | Regular review; suggestions welcome. 定期檢討。 |
