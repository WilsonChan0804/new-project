## At a glance 重點摘要 {#at-a-glance}

=== "English"

    - **Corrigenda** to the FRC Code 1996, e.g. deleting "but in no case less than 2 hours" in para. 7.2, adding a "fire door to be kept closed" sign diagram, and correcting the cover for **2-hour RC floors to 25 mm** (not 40 mm) (para. 1).
    - **Openings in compartment walls** (para. 10.1, revised): total width **≤ 25%** of wall length needs doors or shutters matching the wall's **integrity**; **> 25%** needs integrity **and insulation**, with insulation reducible to **30 min** if extra sprinklers cover both sides (para. 2).

=== "中文"

    - 1996 年耐火結構守則的**勘誤**，例如刪除第 7.2 段「但在任何情況下不少於 2 小時」、加入「防火門應常關」標誌圖，以及把 **2 小時鋼筋混凝土樓板的保護層更正為 25 毫米**（非 40 毫米）（第 1 段）。
    - **防火間隔牆的開口**（修訂第 10.1 段）：開口總闊度 **≤ 牆長 25%** 時，門或防火捲閘須在**完整性**方面與牆相同；**> 25%** 時須在完整性**及隔熱性**方面相同，如門兩側加設花灑，隔熱性可減至 **30 分鐘**（第 2 段）。

!!! warning "Superseded for new works 新工程已不適用"
    Listed in [APP-153 Appendix A](app-153.md#appendix-a). The 25% opening rule in para. 2(i) is carried into **FS Code C8.1**. 第 2(i) 段規則已納入消防守則 C8.1。

## Key clauses 條文一覽 {#key-clauses-table}

| Para. 段 | Rule 規定 |
|---|---|
| 1(i) | FRC Code 1996 para. 7.2: delete "but in no case less than 2 hours". 刪除「不少於 2 小時」。 |
| 1(ii) | Para. 17.2: add the **"FIRE DOOR TO BE KEPT CLOSED 防火門應常關"** notice. 加入告示。 |
| 1(iii) | Table C: concrete cover for **2 h** continuous RC floors and landings **25 mm** (not 40 mm). 保護層 25 毫米。 |
| 2(i) | Para. 10.1 openings in compartment walls (communication, not combination), with doors or shutters: total width **≤ 25%** of the wall: **integrity** only; **> 25%**: integrity **and insulation**, insulation reducible to **30 min** with sprinklers on **each side** (FSI Code; LPC Rules / BS EN 12845). For consents (foundation consent for new buildings) **on or after 18 Aug 2011**. 開口 25% 規則。 |
| 2(ii)–(iii) | p.14: openings "with an FRP as described in (iii)"; p.32: "fixed light with **FRP ≥ ½ FRPe**". 文字修訂。 |
| 3 | A **raised floor ≤ 600 mm** above the structural floor is not an element of construction and needs no FRP; compartment walls must start from the **structural floor**. 架空地台。 |
| 4 | Updated code on BD's website. 網上版本。 |
