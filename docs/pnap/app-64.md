## At a glance 重點摘要 {#at-a-glance}

=== "English"

    - Adopts **GEOSPEC 3 – Model Specification for Soil Testing** (GEO): **32** classification and compaction tests (App. A) and **7** shear strength and compressibility tests (App. B) (para. 1).
    - Developed from a GEO review of **BS 1377:1990** (GEO Report No. 36 for Phase I) (para. 2).
    - AP, RSE and RGE should **specify GEOSPEC 3** for soil testing in investigation, design and construction (para. 3).

=== "中文"

    - 採用土力工程處的 **GEOSPEC 3 土壤測試標準規格**：**32** 項分類及壓實測試（附錄 A）及 **7** 項剪力強度及壓縮性測試（附錄 B）（第 1 段）。
    - 由土力工程處檢討 **BS 1377:1990** 發展而成（第一階段為 GEO 報告第 36 號）（第 2 段）。
    - 認可人士、註冊結構工程師及註冊岩土工程師在勘測、設計及施工中應**指定採用 GEOSPEC 3**（第 3 段）。

!!! tip "Does it apply? 是否適用"
    **Applies 適用**: all **soil tests** supporting plans, approval / consent conditions (s.17(1) item 6(b)), GI in Scheduled Areas, site formation plans and fill compaction records: use **Geospec 3**, by **HOKLAS**-accredited labs. 土壤測試須按 Geospec 3 及由認可實驗室進行。

## Key clauses 條文一覽 {#key-clauses-table}

| Para. 段 | Rule 規定 |
|---|---|
| 1 | **Geospec 3 – Model Specification for Soil Testing** (GEO): **32 Expanded Phase I** tests (classification, compaction; App. A) and **7 Phase II** tests (shear strength, compressibility; App. B). 32 + 7 項測試。 |
| 2 | Background: GEO review of **BS 1377:1990**; Phase I first in **GEO Report No. 36** (1994). 背景。 |
| 3 | Adopt Geospec 3; plans or consent may be **refused** if soil tests are not to it; fill completion certificates may not be accepted otherwise ([APP-15](app-15.md)). 不符合可拒批。 |
| 4 | Only **HOKLAS-accredited** labs; only **HOKLAS-endorsed** certificates accepted (HOKLAS 009 directory; Geospec 3 clause 2.3). 認可實驗室。 |
| 5 | **Credibility** of data matters (disapproval and sanctions for misrepresentation): test schedule fits the geology; supervise sampling, storage, transport; careful testing and vetting; reproduce reports only **in full**. 數據可信性。 |
| 6 | Tests on or after **1 Jul 2004**: only labs accredited **to Geospec 3**. 2004 年 7 月 1 日後。 |
| 7 | Tests before 1 Jul 2004: GEO Report 36 Phase I certificates (App. C) still accepted. 之前的測試。 |
| App. A–C | Lists of test methods (moisture content, Atterberg limits, particle density and size, compaction, etc.; Phase II strength and consolidation). 測試方法表。 |

## Paragraph by paragraph and appendices (full) 逐段及附錄詳解 {#paragraph-detail}

Checked against the BD copy, revision December 2005. GEO has since issued later editions of Geospec 3. Check which edition HOKLAS laboratories are accredited for. The old PNAP 55 cited in para. 3 is now [APP-15](app-15.md). 已按 2005 年版本核對。

| Para. 段 | Content 內容 |
|---|---|
| 1 | BD adopts **Geospec 3** (GEO, CEDD): **32** Expanded Phase I tests (classification, compaction) in Appendix A and **7** Phase II tests (shear strength, compressibility) in Appendix B. |
| 2 | Background: GEO's 1992 review of BS 1377:1990. Phase I became GEO Report No. 36 (PNAP 167 first issue, 1994). Phase II and the expanded Phase I are now in Geospec 3. |
| 3 | AP/RSE/RGE should specify Geospec 3. The BA **may refuse approval or consent** if soil tests supporting plans or s. 17(1) item 6(b) conditions were not done to Geospec 3, including GI plans in Scheduled Areas, site formation plans and other geotechnical plans. Fill density and compaction tests not to Geospec 3 may mean the **filling completion certificate is not accepted** ([APP-15](app-15.md)). |
| 4 | Only **HOKLAS**-accredited laboratories for the relevant tests, with **HOKLAS-endorsed** certificates. Check the HKAS directory (HOKLAS 009). Laboratory selection: Geospec 3 cl. 2.3. |
| 5 | Data credibility: misrepresentation can lead to disapproval and sanctions. Good practice: (i) a test schedule matched to the site geology with soil type information; (ii) supervised sampling, storage, transport and preparation to avoid disturbance and keep samples secure; (iii) careful testing, documentation and vetting; (iv) reproduce HOKLAS reports **only in full**, and clarify doubts with HKAS. |
| 6 | Tests on or after **1 July 2004**: only HOKLAS reports from laboratories accredited **to Geospec 3**. |
| 7 | Tests **before 1 July 2004**: GEO Report 36 Phase I results still accepted (Appendix C); Geospec 3 equivalents also accepted. |

### Appendix A: Expanded Phase I tests in Geospec 3 (Rev. 5/2004) 第一期擴展測試

| Test method 方法 | Test 測試 |
|---|---|
| 5.1 / 5.2 / 5.3 | Moisture content by oven drying at **45 ± 5 °C** / **105 ± 5 °C** / comparative test |
| 6.1 / 6.2 | Liquid limit, plastic limit and plasticity index / liquidity index |
| 7.1 / 7.2 | Particle density: gas jar / small pyknometer |
| 8.1–8.7 | Particle size distribution: wet sieving, pipette and hydrometer, each with and without dispersant; combined continuous curve (8.7) |
| 9.1–9.5 | Organic matter; mass loss on ignition; sulphate content (soil, groundwater, extracts, gravimetric); water-soluble chloride; pH |
| 10.1–10.8 | Dry density / moisture content (compaction). 1000 cc or CBR mould; **2.5 kg** or **4.5 kg** rammer; particles not susceptible / susceptible to crushing (8 combinations) |
| 11.1 / 11.2 | In-situ density by **sand replacement**, small cylinder (fine / medium) / large cylinder (fine, medium, coarse) |
| 11.3 | In-situ density by **nuclear densometer** (fine / medium) |
| 11.4 | **Relative compaction** of fill |
| 12.1 | California Bearing Ratio (CBR) |

### Appendix B: Phase II tests (5/2004) 第二期測試

| Test method 方法 | Test 測試 |
|---|---|
| 14.1 / 14.2 | One-dimensional consolidation / isotropic compression in a triaxial cell |
| 15.1 | Unconsolidated undrained triaxial (UU), no pore pressure |
| 15.2 | Isotropically consolidated undrained triaxial (CIU), with pore pressure |
| 15.3 | Isotropically consolidated drained triaxial (CID), with volume change |
| 16.1 / 16.2 | Direct shear: small / large shear box |

### Appendix C: GEO Report 36 Phase I tests and Geospec 3 equivalents (5/2004) 舊標準對照

| GEO Report 36 | Geospec 3 |
|---|---|
| 2.3.2A / 2.3.2B / 2.3.2C (moisture at 105 °C / 45 °C / comparative) | 5.2 / 5.1 / 5.3 |
| 2.4.3, 2.5.3 (liquid limit by cone; plastic limit, PI, LI) | 6.1 and 6.2 |
| 2.9.2A/B, 2.9.4A/B, 2.9.5A/B, 2.9.6 (particle size) | 8.1–8.7 |
| 4.3.3A/B, 4.3.4A/B (compaction, 2.5 kg rammer) | 10.1–10.4 |
| 9.2.1 / 9.2.2 (sand replacement) | 11.1 / 11.2 |

Notes: follow GEO Report 36 Appendix A for laboratory requirements and sample preparation. Give the laboratory the **soil type and oven-drying temperature** for every moisture content test.
