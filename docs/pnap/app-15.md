## At a glance 重點摘要 {#at-a-glance}

=== "English"

    - Loose, unretained fill can cause **flowslides**. Where a fill slope failure could endanger the public, BA requires **drawings** of the filling to App. A standards, with **RGE periodic supervision** and qualified supervision (paras. 1–2).
    - Give BA **notice of commencement**; submit **monthly compaction test reports** with an RGE-signed assessment (in-situ density vs. max dry density of the same soil) (paras. 3–4).

=== "中文"

    - 鬆散而無承托的填土可引致**流動性山泥傾瀉**；如填土斜坡倒塌可危及公眾，建築事務監督會要求按附錄 A 標準呈交填土**圖則**，並由**註冊岩土工程師定期監督**及執行合資格監督（第 1–2 段）。
    - 須通知建築事務監督**動工日期**；每月提交**壓實測試報告**及由註冊岩土工程師簽署的評估（同類泥土的現場密度與最大乾密度比較）（第 3–4 段）。

!!! tip "Does it apply? 是否適用"
    **Applies 適用**: **temporary or permanent fill** in private building works where a **fill slope failure could endanger the public** (BA's opinion): drawings, monthly compaction reports and as-built records to **Appendix A**. 可能危及公眾的填土工程。

## Key clauses 條文一覽 {#key-clauses-table}

| Para. 段 | Rule 規定 |
|---|---|
| 1 | Beware **flowslides** of loose, unretained fill; poor compaction still found. 鬆散填土流動滑坡。 |
| 2 | BA requires **filling drawings** to Appendix A; the **RGE** supervises per the supervision plan (TM s.39A) and **qualified supervision** (s.17(1)(6)(e), [APP-28](app-28.md)). 須呈交填土圖則。 |
| 3 | **Notify** the BA of the start date. 通知動工日期。 |
| 4 | **Monthly reports** signed by the RGE: in-situ density, lab compaction, **relative compaction**, non-compliances and **corrective measures**; same soil type and source for both tests; records on site. 每月報告。 |
| 5 | If fill may be loose, BA checks with **GCO probes** and **trial pits** (AP / RGE provides labour). 現場抽查。 |
| 6 | Loose fill: density tests witnessed by BD / GEO; extensive loose fill → **Cease Works Order** (s.23 or 24A). 停工令。 |
| 7 | Before completion certificate and OP: **as-built** plans and sections, and **complete test records**. 完工資料。 |
| 8 | Structural works: RSE signs calculations, assessments and certifies completion. 結構工程。 |
| 9 | OP normally **refused** (s.21(6)(a)) if temporary fill not removed or permanent fill not to Appendix A. 不符合拒發佔用許可證。 |

## Appendix A: standards for filling 附錄 A：填土標準 {#appendix-a}

| Item | Requirement 要求 |
|---|---|
| (1) | Peripheral fill of an earth fill slope: field dry density **≥ 95%** of max. dry density |
| (2) | Max. dry density and optimum moisture by **Geospec 3**; test each soil type when first used and with every set of field tests; record location and level (PD); keep graphs and sheets |
| (3) | Field density and moisture by Geospec 3, number per **Table 1**; small fills (< **1 m** deep and < **300 m³**) may test less with penetration tests |
| (4) | Relative compaction by Geospec 3, max. density from the **same batch / source** |
| (5) | **HOKLAS**-accredited laboratories only |

| Table 1: tests per batch 每批測試數量 | Area of fill | No. of determinations |
|---|---|---|
| Excavations for structures, pits, trenches, formations | 0–100 m² | 3 |
| | 100–500 m² | 2 per 100 m² |
| | > 500 m² | 1 per 100 m² |
| Other areas | 0–1 ha | 4 per 1,000 m² |
| | 1–10 ha | 3 per 1,000 m² |
| | > 10 ha | 2 per 1,000 m² |

!!! example "Illustrative only 只作說明"
    A 3,000 m² fill platform with a peripheral slope (one batch of CDG): "other areas, 0–1 ha" → 4 per 1,000 m² → **12** density tests for that batch, each paired with a max. dry density test on the same soil; peripheral fill must reach **95%** (APP-109 allows **90%** in the interior of a large non-structural platform). 3,000 平方米填土例子。
