## At a glance 重點摘要 {#at-a-glance}

=== "English"

    - How the 1995 / 1996 MOA, FRC and MOE Codes apply where the law is silent (paras. 1–2):
    - **A&A**: only the **affected areas** (including shared exits) must follow the revised codes. **Restaurant licensing**: only the area under the new licence. **Consent** on plans approved before a code's effective date is generally given if sought **within 2 years** of approval.
    - **Occupancy** may be assessed by **head counts** in the premises or comparable premises if shown to be truly similar (location, management, patronage, type, age); for new buildings, prescriptive values give a margin for future change.

=== "中文"

    - 在法例未有明文規定的情況下，1995／1996 年救援通道、耐火結構及走火守則的應用（第 1–2 段）：
    - **改動加建**：只有**受影響範圍**（包括共用出口）須符合修訂守則；**食肆發牌**：只限新申請牌照的範圍；守則生效前已批准的圖則，如在批准後 **2 年內**申請，一般會給予**同意**。
    - **人數**可按該處所或確屬相若處所（位置、管理、顧客、類型、樓齡）的**實際點算**評估；新建築物採用規定數值可為日後改變預留空間。

!!! warning "Superseded for new works 新工程已不適用"
    Listed in [APP-153 Appendix A](app-153.md#appendix-a). The same principles (A&A affects only the works area and its exits; licensed premises; 2-year consent rule) are restated for the FS Code 2011 in **APP-153 para. 3**. 相同原則已在 APP-153 第 3 段重申。

## Key clauses 條文一覽 {#key-clauses-table}

| Para. 段 | Rule 規定 |
|---|---|
| 1 | Revised codes: **MOA 1995**, **FRC 1996**, **MOE 1996**. 三份修訂守則。 |
| 2(i) | **A&A**: only the **affected areas** (incl. **shared exits**) follow the revised codes. 只限受影響範圍。 |
| 2(ii) | **Restaurant licensing**: only the area under the **new licence** application. 食肆發牌同上。 |
| 2(iii) | Plans approved before the codes' effective dates: consent generally given if applied for **within 2 years** of approval. 兩年內申請同意。 |
| 2(iv) | **Occupancy by head count** in the premises or comparable premises accepted if comparables are similar (location, management, patronage, class, type, age); new buildings may prefer **prescriptive** factors for future flexibility. 可用實際點算人數。 |
| 3 | The codes allow a **fire engineering approach**; procedures to follow (later APP-87, now FS Code Part G). 消防工程方法。 |
