# Specified forms 指明表格

!!! info "About this section 關於本部分"
    | | |
    |---|---|
    | **Source 來源** | [BD forms: new buildings and A&A works](https://www.bd.gov.hk/en/resources/forms/form_nbw.html) · [Minor works forms](https://www.bd.gov.hk/en/resources/forms/form_mw.html) |
    | **Legal basis 法律依據** | Specified under [BO s.22(4)](../regulations/bo-part-2-enforcement.md); list in [APP-60](../pnap/app-60.md) |
    | **Form revisions 表格版本** | As listed on the BD page, checked 2026-11-23 |
    | **Limit 限制** | The BA-series PDF forms could not be downloaded here (eform1.bd.gov.hk refused the connection). BA entries are based on the B(A)R, the BO and the PNAPs, so check the fields against the current form. 未能下載 BA 系列表格原文，內容按法例及作業備考整理，請以現行表格核對。 |

Forms must be used **unaltered**, in the latest version, and filled on computer so the QR code holds the data ([APP-60](../pnap/app-60.md) paras. 1–8). Minor amendments to a submitted form: [ADM-14](../pnap/adm-14.md). Electronic submission (ESH / EFSS / RMWMS): [ADM-17](../pnap/adm-17.md).
表格須**原樣**使用最新版本，以電腦填寫；已呈交表格的輕微修訂見 ADM-14；電子呈交見 ADM-17。

## Which form when? 何時用哪份表格 {#sequence}

### Building works under BO s.14 (approval and consent) 須批准及同意的建築工程

| Stage 階段 | Form 表格 | Deadline 時限 | Basis 依據 |
|---|---|---|---|
| 1. Appoint the team 委任 | [BA4](nb-aa.md#ba4) | With the first plan submission 首次呈交圖則時 | BO s.4 |
| 2. Submit plans 呈交圖則 | [BA5](nb-aa.md#ba5) (+ [BA6](nb-aa.md#ba6) for A&A; [BA16](nb-aa.md#ba16) for modification) | BA decides in **60 / 30 days** 60／30 天 | B(A)R regs 18, 18A, 29, 30 |
| 3. Apply for consent 申請同意 | [BA8](nb-aa.md#ba8) / [BA8A](nb-aa.md#ba8a) | BA decides in **28 days** 28 天 | B(A)R regs 31–32 |
| 4. Notify start 開工通知 | [BA10](nb-aa.md#ba10) + [SP](nb-aa.md#sp) | **≥ 7 days** before works start 開工前 7 天 | B(A)R reg 20 |
| 5. During works 施工期間 | [BA9](nb-aa.md#ba9), [BA11](nb-aa.md#ba11), [BA20](nb-aa.md#ba20), [BA21](nb-aa.md#ba21), [Forms A–C](nb-aa.md#forms-a-c) | Changes notified **within 7 days** 7 天內 | B(A)R regs 22–24, 34 |
| 6. Completion 完工 | [BA12](nb-aa.md#ba12) / [BA13](nb-aa.md#ba13) / [BA14](nb-aa.md#ba14) / [BA14A–C](nb-aa.md#ba14a) | Contractor **7 days**, AP **14 days** after completion 7／14 天 | B(A)R regs 25–26; BO s.21 |
| 7. After OP 佔用許可證後 | [Appendices I–IV](nb-aa.md#appendices) | Rectification works 修正工程 | [APP-13](../pnap/app-13.md) |

### Minor works under the B(MW)R 小型工程

| Class 級別 | Before 開工前 | After 完工後 | Basis 依據 |
|---|---|---|---|
| **I** | [MW01](mw.md#mw01) **≥ 7 days** before, with plans and [SP](mw.md#sp) | [MW02](mw.md#mw02) **within 14 days** | B(MW)R ss. 30–32 |
| **II** | [MW03](mw.md#mw03) **≥ 7 days** before | [MW04](mw.md#mw04) **within 14 days** | B(MW)R ss. 33–35 |
| **III** | — | [MW05](mw.md#mw05) **within 14 days** | B(MW)R s.36 |
| Validation 檢核 | — | [MW06-1/2/3](mw.md#mw06) + [VSR](mw.md#vsr) | B(MW)R s.62; BO s.39C |
