## BA4 Notice of Appointment of AP / RSE / RGE<br><small>委任認可人士／註冊結構工程師／註冊岩土工程師通知</small> {#ba4}

| | |
|---|---|
| **Revision 版本** | 03/2019 |
| **Purpose 目的** | Owner tells BA who is appointed as AP, and RSE / RGE where structural or geotechnical works are involved. 業主通知建築事務監督所委任的認可人士，以及（涉及結構或岩土工程時）註冊結構／岩土工程師。 |
| **When 何時** | Before or with the first submission of plans (BA5); again whenever an appointment changes. 首次呈交圖則（BA5）前或同時；委任有變時再交。 |
| **By 由誰** | Owner, with acceptance signed by each appointee 業主，獲委任人士簽署接受 |
| **Legal basis 法律依據** | [BO s.4](../regulations/bo-part-2-building-works.md); [B(A)R reg. 22](../regulations/bar-123a.md#regulation-by-regulation) (changes within 7 days) |
| **Related 相關** | [ADM-19](../pnap/adm-19.md) · [ADM-2](../pnap/adm-2.md) |
| **Submit with 附交文件** | Owner's particulars and signature; registration numbers of the AP / RSE / RGE. 業主資料及簽署；各人註冊編號。 |

## BA5 Application for Approval of Plans and Certificate of Preparation of Plans<br><small>申請批准建築工程及／或街道工程圖則及擬備圖則證明書</small> {#ba5}

| | |
|---|---|
| **Revision 版本** | 03/2019 |
| **Purpose 目的** | Apply for approval of building works or street works plans (BO s.14(1)(a)), with the AP / RSE / RGE certificate that the plans were prepared under their supervision and comply with the BO. 申請批准圖則，並由認可人士等證明圖則在其監督下擬備及符合條例。 |
| **When 何時** | Each first submission and each resubmission of plans. BA decides within **60 days** (first submission or major revision) or **30 days** (other resubmissions). 首次呈交及每次再呈交；60／30 天內決定。 |
| **By 由誰** | AP / RSE / RGE (with BA4 owner appointment) 認可人士等 |
| **Legal basis 法律依據** | [B(A)R regs 8–14, 18A, 29, 30, 42](../regulations/bar-123a.md#key-table-processing-periods); BO s.14–16 |
| **Related 相關** | [ADM-19](../pnap/adm-19.md) approval process · [ADM-2](../pnap/adm-2.md) centralised processing · [ADM-9](../pnap/adm-9.md) colouring · [ADM-17](../pnap/adm-17.md) e-submission · [ADM-15](../pnap/adm-15.md) site formation · [APP-57](../pnap/app-57.md) ELS plans |
| **Submit with 附交文件** | Prescribed plans (reg. 8): block plan ≥ 1:500, building plans ≥ 1:100, sections, drainage, structural and foundation plans as applicable; structural calculations; site formation / GI reports ([APP-49](../pnap/app-49.md)); one coloured copy (reg. 14, ADM-9); plan fee (reg. 42); BA6 for A&A works; BA16 if modification is sought; GFA / SC / PR calculations ([GFA guide](../guides/gfa.md)). 訂明圖則、結構計算書、岩土報告、着色副本、費用等。 |

## BA7 Notice of Urgent Works Required as a Result of Accident or Emergency<br><small>因意外或緊急事故需要進行緊急工程的通知</small> {#ba7}

| | |
|---|---|
| **Revision 版本** | 03/2019 |
| **Purpose 目的** | Reports building works or street works done urgently, without prior approval and consent, because of an accident or emergency. 報告因意外或緊急情況而未經批准及同意進行的緊急工程。 |

## BA8 Application for Consent to the Commencement and Carrying out of Building Works or Street Works<br><small>申請同意展開及進行建築工程或街道工程</small> {#ba8}

| | |
|---|---|
| **Revision 版本** | 03/2019 |
| **Purpose 目的** | Apply for consent to start works shown on approved plans (BO s.14(1)(b)). Works must not start without consent. 申請同意展開已獲批准圖則的工程；未獲同意不得動工。 |
| **When 何時** | After (or together with) plan approval; BA decides within **28 days**. Part consent is possible. 圖則獲批准後（或同時）；28 天內決定，可分部分同意。 |
| **By 由誰** | AP (with RSE / RGE where applicable) 認可人士 |
| **Legal basis 法律依據** | [B(A)R regs 31–32](../regulations/bar-123a.md#key-table-processing-periods); BO s.14 |
| **Related 相關** | [APP-97](../pnap/app-97.md) consent procedures · [APP-23](../pnap/app-23.md) hoardings · [APP-21](../pnap/app-21.md) demolition safety · [Demolition code](../codes/demolition-2004.md) |
| **Submit with 附交文件** | Reference to the approved plans; name of the registered contractor (if known); for demolition: particulars of powered mechanical plant and operators (reg. 31); undertakings / precautionary measures where required by approval conditions (e.g. ELS, monitoring). 已批准圖則編號；承建商；拆卸工程的機械及操作員資料；批准條件要求的措施。 |
